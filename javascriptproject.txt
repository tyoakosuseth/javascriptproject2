Test 2: Registered Customer with Insufficient Airtime
Inputs:
customerName = "Seth";
isRegistered = true;
airtimeBalance = 200;
selectedBundle = 2;


Expected Output:
Purchase rejected: Insufficient airtime


Actual Output:
Purchase rejected: Insufficient airtime

Explanation:
The customer has ₦200, and bundle code 2 costs ₦350. Since the airtime is less than the bundle price, the purchase is rejected.

Test 3: Unregistered Customer with Sufficient Airtime
Inputs:
customerName = "John";
isRegistered = false;
airtimeBalance = 2000;
selectedBundle = 2;


Expected Output:
Purchase rejected: Customer is not registered


Actual Output:
Purchase rejected: Customer is not registered

Explanation:
The customer has enough airtime but is not registered. Registration is required, so the purchase is rejected.

Test 4: Invalid Bundle Code

selectedBundle = 9;


Expected Output:
Invalid bundle code
Purchase rejected: Invalid bundle


Actual Output:
Invalid bundle code
Purchase rejected: Invalid bundle


Explanation:
Bundle code 9 is not among the available bundle options. The program identifies it as invalid and prevents the purchase.
